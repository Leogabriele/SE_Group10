# SE Group 10

# 🏥 Smart WhatsApp Assistant for Clinics

## 📌 Problem Statement  

To design and develop an intelligent WhatsApp chatbot system that automates doctor appointment booking, patient query handling, and real-time doctor notifications, thereby reducing manual effort, improving communication efficiency, and enhancing patient experience.

---

## 🎯 Expected Outcome  

The Smart WhatsApp Assistant will:

- Enable patients to book, reschedule, and cancel appointments through WhatsApp.
- Automatically store patient and appointment data securely.
- Send real-time notifications to doctors for new or updated bookings.
- Provide instant responses to frequently asked patient queries.
- Reduce manual administrative workload in clinics.
- Improve response time and overall patient satisfaction.
- Minimize scheduling errors and double bookings.

---

## 🧠 Hypothesis  

If clinics implement an AI-powered WhatsApp assistant for appointment management and patient communication, then:

- Administrative workload will significantly decrease.
- Appointment scheduling errors will reduce.
- Response time to patient queries will improve.
- Patient satisfaction and engagement will increase.

Because automation ensures 24/7 availability, faster communication, and reduced human error.

---

## 🛠 Tech Stack  

- **Frontend:** React.js *(Dynamic and responsive UI)*  
- **Backend:** Node.js with Express.js *(API handling and business logic)*  
- **Authentication:** Firebase Authentication *(Secure login and account management)*  
- **Database:** MongoDB *(Storing patient and appointment data)*  
- **Cloud Storage:** Firebase Storage *(Managing and hosting files if needed)*  
- **Deployment:** Firebase Hosting / Vercel (Frontend) and AWS / Heroku (Backend)
